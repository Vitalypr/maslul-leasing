# מסלול — מחשבון ליסינג לעובדים

מחשבון שמראה לעובד את **העלות הנטו האמיתית** של כל רכב בצי הארגוני — לחודש, לשנה
ולשלוש שנים — אחרי השתתפות המעסיק, אחרי זקיפת שווי השימוש למס, ואחרי דלק או חשמל.

**האפליקציה רצה כולה בדפדפן. שכר, מרחק מהבית ושאר הנתונים האישיים נשמרים ב־localStorage
בלבד ואינם עוזבים את המכשיר.** אין שרת ואין מסד נתונים.

## התקנה בטלפון

פתחו את הכתובת בכרום באנדרואיד ובחרו **התקנת אפליקציה** בתפריט. האפליקציה נפתחת
במסך מלא ועובדת אופליין.

## הרצה מקומית

```bash
npm install
npm run dev
```

## מבנה

```
src/engine/    מנוע חישוב — TypeScript טהור, ללא React וללא DOM. טוהר נאכף ב-ESLint.
src/data/      נתונים בלבד: קטלוג, מדיניות, חוקי מס, מחירי אנרגיה
src/features/  מסכים: פרופיל · קטלוג · דף רכב · השוואה · הגדרות מנהל
test/          277 בדיקות
```

הרעיון המרכזי: **כל שורת כסף נושאת סיווג מס מפורש** (`net` · `gross` ·
`taxableBenefit` · `grossedUp`) שנקבע ב־`src/data/policy/org.json` ולא בקוד. שינוי
השאלה "האם רכיב יורד מהברוטו או מהנטו" הוא עריכת מילה אחת.

מבוססות על פרסומי 2026 וטעונות אימות מול רשות המסים לפני שימוש אמיתי. שני רכבים
