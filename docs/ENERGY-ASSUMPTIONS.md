## 2. איך המנוע מחשב

### בנזין, היברידי מתון והיברידי

```
ליטרים בשנה = ק"מ בשנה ÷ קמ"ל
עלות        = ליטרים × מחיר לליטר
```

היברידי רגיל אינו נטען מהרשת, ולכן הוא נמדד בקמ"ל בלבד — החיסכון שלו כבר גלום
בצריכה. **היברידי מתון (mhev) מטופל כבנזין לכל דבר**, לפי ההערה האדומה שלך בשורת
אופל מוקה במחירון.

### חשמלי מלא

```
kWh בשנה = ק"מ × kWh/100 ÷ 100
עלות      = kWh × תעריף
```

אין כרגע רכב חשמלי מלא בצי.

### פלאג־אין — כאן נמצא כל הסיפור

זה החלק שמכריע את כדאיות הפלאג־אין, ולכן הוא מפורש ולא מוסתר.

```
נסיעה יומית      = מרחק חד־כיווני × 2
ימי עבודה בשנה   = ימי עבודה בחודש × 12
נסועה יומית שנתית = min(נסיעה יומית × ימי עבודה, נסועה שנתית)
נסיעות ארוכות    = נסועה שנתית − נסועה יומית שנתית

טווח אפקטיבי = טווח היצרן × 0.70          (או ערך אמת פר־דגם אם קיים)

אם מתוכננת טעינה יומית:
    ק"מ חשמליים ליום = min(נסיעה יומית, טווח אפקטיבי)
    ק"מ חשמליים בשנה = ק"מ ליום × ימי עבודה
אחרת:
    ק"מ חשמליים = 0

ק"מ על דלק = נסועה שנתית − ק"מ חשמליים
```

שלוש הנחות מובנות בזה, וכולן מכוונות:

1. **הסוללה נטענת פעם אחת ביום עבודה.** לא פעמיים, גם אם יש עמדה בעבודה.
2. **נסיעות ארוכות רצות על דלק בלבד.** נסיעה שעולה על הטווח החשמלי מבזבזת אותו בתחילתה
   וממשיכה על מנוע הבנזין.
3. **התקרה `min` פועלת לשני הכיוונים.** מי שנוסע 10 ק"מ ביום לא ינצל טווח של 60 ק"מ,
   ומי שנוסע 200 ק"מ ביום לא יקבל יותר מהטווח.

**מקדם 0.70** ❗ הוא הנחה שלי, לא מדידה. ביקשת "נתוני אמת ולא יצרן", וזו הדרך הזולה
לייצג את הפער. הוא פרמטר במסך המנהל. הסכמה תומכת גם ב־`realEvRangeKm` פר־דגם שגובר
עליו — **כרגע הוא לא מוגדר לאף רכב.**

מקדם הטווח נעצר להשתפר מעל 0.8: בטווח מוצהר 85 ק"מ, `0.8 × 85 = 68` שווה בדיוק
לנסיעה היומית בפרופיל הייחוס. מעבר לזה התקרה `min(נסיעה יומית, טווח)` חוסמת, וטווח
נוסף אינו שווה כלום לנהג הזה. **זו תובנת רכישה אמיתית** — טווח חשמלי מעבר לנסיעה
היומית שלך הוא כסף שלא יחזור.

הרגישות הגדולה ביותר היא לצריכה עצמה: סטייה של 15% מזיזה את עלות הדלק ב־כ־₪2,000
בשנה לרכב. זו הסיבה שהחלפת ההערכות בנתוני יבואן היא הצעד הבא בעל הערך הגבוה ביותר.

## 6. איך מחליפים את ההערכות

בקובץ `src/data/catalog/fleet-2026.json`, לכל רכב:

```jsonc
"consumption": {
  "kmPerLiter": 15.5,          // בנזין / mhev / היברידי
  "fuel": "petrol95",
  "kwhPer100km": 17.0,         // חשמלי / פלאג־אין
  "evRangeKm": 85,             // פלאג־אין
  "kmPerLiterHybridMode": 18,  // פלאג־אין
  "source": "spec"             // ← "estimate" הופך ל-"spec"
},
"realEvRangeKm": 62            // אופציונלי, גובר על מקדם ה-0.70
```

שינוי `source` ל־`spec` מסיר אוטומטית את התווית "צריכה משוערת" מהממשק. אין צורך
לגעת בקוד.

**מקורות מומלצים:** מפרט היבואן, או נתוני צריכה מוצהרים במאגר משרד התחבורה. עבור
הפלאג־אין, אם תשיג טווח חשמלי נמדד בפועל, מלא `realEvRangeKm` — הוא מדויק בהרבה
ממקדם גורף.
